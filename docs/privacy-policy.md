# 아케이드박스 개인정보처리방침

시행일: 2026년 11월 20일

아케이드박스 운영자(이하 "운영자")는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 관련 고충을 빠르게 처리하기 위해 이 방침을 둬요.

아케이드박스는 **토스 미니앱**과 **안드로이드 앱** 두 가지로 제공되고, 두 앱이 다루는 정보가 달라요.

## 한눈에 보기

| | 토스 미니앱 | 안드로이드 앱 |
|---|---|---|
| 이름 · 전화번호 · 이메일 같은 정보 | 받지 않아요 | 받지 않아요 |
| 게임 기록을 두는 곳 | 운영자 서버와 기기 | 기기에만 |
| 사용자 구분 | 토스가 이 게임용으로 발급하는 사용자 식별키 | 하지 않아요 |
| 광고 · 유료 결제 | 토스가 제공해요 | 없어요 |

## 1. 처리하는 정보와 목적

### 토스 미니앱

| 항목 | 목적 | 보유 기간 |
|---|---|---|
| 사용자 식별키 (토스가 이 게임에서만 쓰도록 발급하는 값) | 기기가 바뀌어도 같은 사용자의 기록을 이어 주기 | 삭제를 요청하거나 서비스를 끝낼 때까지 |
| 게임 기록: 게임별 코인, 최고 점수와 기록, 깬 단계, 열린 게임, 가진 아이템과 장착한 아이템, 효과음 · 진동 설정 | 이어하기, 순위표, 상점 | 위와 같음 |
| 판별 결과: 게임 종류, 점수, 얻은 코인, 시각 | 순위표, 비정상적인 기록 막기 | 위와 같음 |
| 출석 보상 · 광고 보상을 받은 날짜와 횟수 | 하루 보상 횟수 제한 | 위와 같음 |
| 접속 토큰 (서버에는 되돌릴 수 없는 해시값으로만 저장) | 접속 상태 유지 | 발급 후 30일 |

- 사용자 식별키는 토스 앱이 발급한 인증 코드를 운영자 서버가 토스 서버와 교환해서 받아요. 운영자는 토스 계정의 이름, 전화번호 같은 정보를 받지 않아요.
- 순위표에는 사용자 식별키로 만든 "플레이어 1A2B" 같은 가명만 보여요.
- 같은 게임 기록을 기기에도 저장해 둬요. 유료 아이템의 주문번호와 상품은 **기기에만** 저장하고 서버로 보내지 않아요.
- 운영자 서버는 IP 주소 같은 접속 기록을 따로 저장하지 않아요. 다만 서버로 가는 통신은 4번의 Cloudflare를 거치고, 이 과정에서 IP 주소 같은 통신 정보가 처리될 수 있어요.

### 안드로이드 앱

안드로이드 앱은 개인정보를 수집하지 않아요. 회원가입과 로그인이 없고, 외부 서버와 통신하지 않아요.

게임을 이어서 하기 위해 아래 정보를 **이용자의 기기 안에만** 저장해요.

- 게임별 코인, 최고 점수, 깬 단계
- 코인으로 산 아이템과 장착한 아이템
- 효과음 · 진동 설정, 출석 보상을 받은 날짜

앱을 지우면 이 정보도 함께 지워져요. 안드로이드 기기 백업을 켜 두었다면 이용자의 구글 계정 백업에 포함될 수 있지만, 운영자는 이 백업을 볼 수 없어요.

## 2. 제3자 제공

운영자는 이용자의 정보를 제3자에게 제공하지 않아요. 법령에 특별한 규정이 있는 경우만 예외예요.

## 3. 토스가 직접 처리하는 기능 (토스 미니앱)

- **광고**: 보상형 광고는 토스가 보여 줘요. 광고를 보여 주는 데 필요한 정보는 토스가 자체 개인정보처리방침에 따라 처리해요. 운영자는 광고 보상을 받은 날짜와 횟수만 저장해요.
- **결제**: 유료 아이템은 토스 인앱결제로 결제해요. 운영자는 결제 수단 정보를 받지 않고, 주문번호와 상품만 기기에 저장해요.

## 4. 처리 위탁과 국외 이전 (토스 미니앱)

토스 미니앱의 서버를 운영하기 위해 아래 업체에 처리를 맡겨요. 이 과정에서 정보가 국외에 저장되거나 전송돼요.

| 받는 곳 | 국가 | 맡기는 일 | 이전 항목 | 시기와 방법 | 보유 기간 |
|---|---|---|---|---|---|
| Google LLC (Google Cloud)<br>https://cloud.google.com/terms/cloud-privacy-notice | 미국 | 서버와 데이터베이스 운영 | 1번 토스 미니앱 항목 전부 | 게임을 이용할 때 암호화된 통신(HTTPS)으로 전송 | 1번 보유 기간과 같음 |
| Cloudflare, Inc.<br>privacyquestions@cloudflare.com | 미국 등 Cloudflare 데이터센터가 있는 국가 | 서버 앞단의 보안과 전송 | 통신 정보(IP 주소 등)와 전송 중인 데이터 | 위와 같음 | 전송을 처리하는 동안 (Cloudflare 정책에 따라 보관) |

국외 이전을 원하지 않으면 토스 미니앱 대신 안드로이드 앱(서버 통신 없음)을 이용할 수 있어요. 이 경우 기기 간 이어하기와 순위표는 쓸 수 없어요.

## 5. 파기

- 삭제 요청을 받거나 서비스를 끝내면 서버의 정보를 지체 없이, 되살릴 수 없는 방법으로 지워요.
- 기간이 지난 접속 토큰은 자동으로 지워요.
- 기기에 저장한 정보는 이용자가 앱이나 앱 데이터를 지우면 함께 지워져요.

## 6. 이용자의 권리와 행사 방법

- 저장된 기록은 앱 화면(홈, 순위표, 상점, 설정)에서 바로 볼 수 있어요.
- 서버 기록의 삭제나 처리 정지를 원하면 9번의 이메일로 요청해 주세요. 운영자는 요청을 받은 날부터 10일 안에 처리하고 결과를 알려 드려요.
- 법정대리인이나 위임을 받은 사람을 통해서도 요청할 수 있어요.

## 7. 안전성 확보 조치

- 앱과 서버 사이의 모든 통신을 HTTPS로 암호화해요.
- 접속 토큰은 해시값으로만 저장해요.
- 서버와 데이터베이스에 접근할 수 있는 사람을 운영자로 제한하고, 데이터베이스는 외부에서 직접 접속할 수 없게 막아 둬요.
- 토스 서버와의 통신은 상호 인증서(mTLS)로 보호해요.

## 8. 쿠키 같은 자동 수집 장치

아케이드박스는 쿠키를 쓰지 않고, 광고 식별자를 수집하지 않아요.
