# 콘솔 앱 정보 (최초 검토 요청용)

앱인토스 콘솔의 미니앱 `arcade-box`(miniAppId 103066)에 첫 번들과 함께 낼 앱 정보예요. 최초 등록 전에는 앱 정보를 따로 저장할 수 없어서, 첫 검토 요청(`initial_review_submit`) 때 아래 내용을 한꺼번에 내요.

## 상세 설명 (500자 이내)

아케이드박스는 가볍게 즐기는 게임을 한곳에 모은 게임 모음이에요.

핀볼: 화면을 누르고 있으면 발사대 스프링이 당겨지고, 손을 떼면 공이 발사돼요. 오래 누를수록 세게 나가요. 공이 판에 들어가면 화면 왼쪽과 오른쪽을 눌러 플리퍼를 움직이고, 범퍼를 맞히거나 판 위의 동전을 주워 점수를 올려요.

지뢰찾기: 초급, 중급, 고급 세 단계가 있어요. 칸을 눌러 열고, 길게 눌러 깃발을 꽂아요. 큰 판은 두 손가락으로 확대하고 끌어서 옮길 수 있어요. 연 칸, 맞힌 깃발, 걸린 시간으로 점수를 매겨요.

핀볼에서 30,000점을 넘기면 지뢰찾기가 열려요. 게임에서 모은 코인과 출석 보상으로 상점에서 판과 공, 타일을 꾸미고, 게임별 순위표에서 다른 사람들과 기록을 겨뤄요.

## 검토 요청 전에 콘솔 웹에서 할 일

- 앱 정보 → 게임 등급분류 입력 (MCP로는 입력할 수 없고, 없으면 게임 앱은 검토 요청이 막혀요)
- 앱 정보 → 고객센터 정보 확인 (비워 두면 콘솔 계정 이메일이 사용자에게 보여요)
- 사용 연령 확인 (새 앱 기본값 19~99세)
