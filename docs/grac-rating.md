# 게임 등급분류 신청 초안 (아케이드박스)

앱인토스 콘솔의 "게임 등급분류"에 낼 **게임물 등급분류증명서**를 받기 위한 신청서 초안이에요. 아케이드박스는 앱스토어나 구글 플레이에 출시하지 않아서, 스토어 링크 방식은 쓸 수 없고 등급분류를 직접 받아야 해요.

- 신청처: **게임콘텐츠등급분류위원회(GCRB)**
  - 2026년 11월 2일부터 모바일 게임 등급분류(전체이용가~청소년이용불가)는 게임물관리위원회가 위탁해 GCRB가 맡아요. 고스톱·포커 같은 사행성 모사 게임만 게임물관리위원회에 남아요. ([보도](https://sateconomy.co.kr/news/view/1065601232873343))
  - 전체~15세 게임은 **간소화 심의**로 이틀 안에 처리될 수 있다고 해요. 일반 심의는 약 7일이에요.
  - 아래 입력 항목은 [앱인토스 블로그](https://toss.im/apps-in-toss/blog/game_rating_classification)의 게임물관리위원회 신청 화면을 기준으로 썼어요. GCRB 신청 화면도 항목이 비슷할 거라 보고 정리했지만, 다른 칸이 있으면 이 문서에서 가까운 내용을 옮겨 써요.
- 회원가입: GCRB 홈페이지(gcrb.or.kr)에서 업체 또는 개인 회원으로 가입하고 승인을 받아야 신청할 수 있어요. 공동인증서(옛 공인인증서)가 필요하고 GCRB용은 무료로 발급돼요. 본인 확인은 아이핀으로 해요. 승인을 빨리 받으려면 070-4172-6545로 문의해요.
- 수수료: GCRB 모의 수수료 계산 기준(2013년 표라 바뀌었을 수 있어요)으로는 `기초가액 × 이용형태 × 장르 × 한글화`예요. 오픈마켓 등 '기타' 10MB 미만 30,000원 × 네트워크 1.5 × 장르(1군 RPG 4.0 · 2군 2.0 · 3군 1.0) × 한글 1.0이라, 3군이면 45,000원 + 부가세예요. 아케이드박스 번들은 1MB가 안 돼요. 상시 50명 미만·연매출 50억 이하면 결정 후 1개월 안에 신청해 50%를 돌려받을 수 있어요.
- 예상 등급: 전체이용가, 내용정보 해당 없음. 최종 판단은 심의 기관이 해요.

`[직접 입력]`으로 표시한 칸은 신청인 본인 정보라서 초안에 넣지 않았어요.

## 2. 게임물 개요 (신청 5단계)

> 아케이드박스는 토스 앱 안에서 실행되는 미니앱(앱인토스)으로, 핀볼·지뢰찾기·벽돌깨기 세 가지 고전 게임을 모은 캐주얼 게임 모음이에요. 핀볼은 공을 쏘아 플리퍼로 튕기며 점수를 올리는 게임이고, 지뢰찾기는 숫자 단서를 보고 지뢰가 없는 칸을 여는 퍼즐 게임이며, 벽돌깨기는 패들로 공을 튕겨 벽돌을 깨는 게임이에요. 게임을 하며 모은 코인과 출석 보상으로 판·공·발판·맵·패들·벽돌의 모양을 꾸밀 수 있고, 일부 꾸미기 아이템은 인앱결제로 살 수 있어요. 게임별 순위표에서 다른 사용자와 점수를 비교할 수 있어요. 사람이나 생물을 공격하는 표현, 선정적인 표현, 채팅 기능, 확률형 아이템, 베팅 요소는 없어요.

- 담당자 연락 가능 시간: `[직접 입력]`

## 5. 게임물 내용 설명서 (신청 8단계 첨부)

아래를 문서 파일로 옮겨 첨부해요.

### 5-1. 게임 개요

- 게임물 이름: 아케이드박스 (Arcade Box)
- 장르: 아케이드 · 캐주얼 게임 모음 (핀볼, 지뢰찾기, 벽돌깨기)
- 실행 환경: 토스 앱(iOS, Android) 안에서 실행되는 웹 기반 미니앱
- 이용 대상: 토스 앱 사용자 (앱인토스는 현재 만 19세 이상에게 제공돼요)
- 이용 요금: 무료. 꾸미기 아이템 일부만 유료예요

### 5-2. 게임 구성

1. **핀볼**: 처음부터 할 수 있어요.
2. **지뢰찾기**: 핀볼에서 30,000점 이상을 한 번 내면 열려요.
3. **벽돌깨기**: 지뢰찾기 고급을 한 번 깨면 열려요.
4. **상점**: 각 게임의 판·공·발판·맵·패들·벽돌 모양을 바꾸는 꾸미기 아이템을 팔아요.
5. **순위표**: 게임별 최고 점수 순위를 보여 줘요.
6. **설정**: 효과음·진동 켜고 끄기, 유료 아이템 구매 내역, 데이터 저장 안내가 있어요.

### 5-3. 플레이 방법

**핀볼**
- 화면을 누르고 있으면 발사대 스프링이 당겨지고, 손을 떼면 공이 발사돼요. 오래 누를수록 세게 나가요.
- 화면 왼쪽과 오른쪽을 눌러 양쪽 플리퍼를 움직여 공을 쳐 올려요.
- 범퍼를 맞히면 점수를 받고, 판 위에 나타나는 동전에 공을 맞히면 코인을 받아요.
- 레인 보너스로 점수 배율이 최대 5배까지 올라가고, 멀티볼(공 2개) 동안에는 점수가 2배예요.
- 공은 한 판에 3개예요. 3개를 모두 떨어뜨리면 판이 끝나요. 도중에 그만둬도 그때까지 모은 코인은 받아요.

**지뢰찾기**
- 초급, 중급, 고급 세 단계가 있고, 앞 단계를 깨면 다음 단계가 열려요.
- 칸을 누르면 열리고, 길게 누르면 깃발을 꽂아요. 열린 칸의 숫자는 주변 8칸에 있는 지뢰 수예요.
- 큰 판은 두 손가락으로 확대하고 끌어서 옮길 수 있어요.
- 지뢰가 없는 칸을 모두 열면 성공이고, 지뢰 칸을 열면 판이 끝나요.
- 판 안에 숨은 동전 칸을 열면 코인을 받고, 판을 깨면 보너스 코인을 더 받아요.
- 점수는 연 칸 수, 맞힌 깃발 수, 걸린 시간으로 계산해요.

**벽돌깨기**
- 화면을 누른 채 좌우로 움직이면 패들이 손가락을 따라오고, 손을 떼면 패들 위의 공이 출발해요.
- 공을 패들로 받아 튕겨 위쪽의 벽돌을 깨요. 패들의 가운데에 맞으면 곧장, 끝에 맞으면 비스듬히 튀어요.
- 보통 벽돌은 한 번, 단단한 벽돌은 두 번 맞혀야 깨져요. 벽돌을 모두 깨면 보너스 점수를 받고 다음 스테이지로 넘어가요. 스테이지가 오를수록 공이 빨라져요.
- 일부 벽돌은 깨지면 동전이나 아이템을 떨어뜨려요. 패들로 받으면 동전은 코인이 되고, 아이템은 잠시 패들을 넓히거나(넓은 패들), 공을 셋으로 늘리거나(멀티볼), 공을 느리게 해요(느린 공). 아이템은 무작위로 뽑는 상품이 아니라 판 안에서만 쓰이는 효과예요.
- 패들에 닿지 않고 벽돌을 이어서 깨면 점수 배수가 올라가요(최대 5배).
- 공은 한 판에 3개예요. 공을 모두 놓치면 판이 끝나요. 도중에 그만둬도 그때까지 모은 코인은 받아요.

### 5-4. 점수와 순위

- 게임별로 최고 점수를 서버에 저장하고 순위표에 보여 줘요.
- 순위표의 이름은 사용자 ID에서 자동으로 만든 익명 이름(예: "플레이어 3F2A")이에요. 사용자가 이름을 정하거나 입력할 수 없어요.
- 결과 화면에서 점수를 토스 메시지로 친구에게 공유할 수 있어요. 공유 문구는 "핀볼에서 ○○점을 냈어요" 형태로 정해져 있어요.

### 5-5. 코인과 아이템

**코인 얻는 방법**
- 게임 플레이: 핀볼 판 위 동전, 지뢰찾기 숨은 동전과 클리어 보너스, 벽돌깨기 동전 벽돌에서 떨어지는 동전
- 출석 보상: 하루 1번, 50코인
- 보상형 광고: 사용자가 원할 때 광고를 끝까지 보면 50코인, 하루 최대 3번

**코인의 성격**
- 코인은 게임별로 따로 쌓이고(핀볼 코인, 지뢰찾기 코인, 벽돌깨기 코인), 그 게임의 꾸미기 아이템을 사는 데만 써요.
- 코인은 돈으로 살 수 없고, 현금이나 다른 재화로 바꿀 수 없으며, 다른 사용자에게 줄 수도 없어요.

**코인으로 사는 아이템**

| 게임 | 아이템 | 가격 |
|---|---|---:|
| 핀볼 | 노을 판 / 숲 판 / 사탕 판 | 1,000 / 1,500 / 3,000코인 |
| 핀볼 | 금색 공 / 에메랄드 공 | 1,000 / 2,500코인 |
| 지뢰찾기 | 민트 발판 / 복숭아 발판 / 체크무늬 발판 | 1,000 / 1,500 / 3,000코인 |
| 지뢰찾기 | 숲속 맵 / 보물섬 맵 | 2,000 / 4,000코인 |
| 벽돌깨기 | 민트 패들 / 불꽃 패들 | 1,000 / 2,500코인 |
| 벽돌깨기 | 파스텔 벽돌 / 보석 벽돌 | 1,500 / 3,000코인 |

**인앱결제로 사는 아이템 (비소모성, 한 번 사면 계속 사용)**

| 게임 | 아이템 | 판매가 (부가세 포함) |
|---|---|---:|
| 핀볼 | 네온 시티 판 | 3,300원 |
| 핀볼 | 은하수 판 | 5,500원 |
| 핀볼 | 루비 공 | 1,100원 |
| 핀볼 | 불꽃 공 | 2,200원 |
| 핀볼 | 번개 공 | 4,400원 |
| 지뢰찾기 | 한밤 발판 | 3,300원 |
| 지뢰찾기 | 황금 발판 | 5,500원 |
| 지뢰찾기 | 황금 사원 맵 | 4,400원 |

**아이템 능력**
- 꾸미기 아이템 중 일부는 코인을 조금 더 얻게 해 줘요. 핀볼 판은 판 위 동전이 더 자주 나오고(최대 +30%), 공·발판·패들은 동전 하나에서 받는 코인이 늘어요(최대 +40%). 지뢰찾기 맵은 숨은 동전 수를, 벽돌깨기 벽돌은 동전 벽돌 수를 늘려 줘요.
- 지뢰찾기 유료 발판에는 판마다 지뢰를 1번 막아 주는 능력이 있어요. 이 능력을 쓴 판은 점수의 70%만 받아서 순위에서 유리하지 않아요.
- 그 밖의 능력은 점수와 순위에 영향을 주지 않아요.
- 모든 아이템은 가격과 내용이 고정돼 있어요. 무작위로 아이템이 나오는 뽑기는 없어요.

### 5-6. 결제와 환불

- 결제는 토스 앱 인앱결제로만 처리해요.
- 산 아이템은 토스 구매 내역에 남아서, 기기를 바꿔도 다시 받을 수 있어요.
- 환불된 아이템은 회수해요. 설정 화면에서 결제·환불 내역을 볼 수 있어요.

### 5-7. 광고

- 보상형 광고만 써요. 상점의 "광고 보고 코인 50개 받기" 칸에서 사용자가 "광고 보기" 버튼을 직접 눌렀을 때만 재생돼요.
- 하루 최대 3번이고, 광고를 끝까지 봤을 때만 코인을 줘요.
- 게임 화면을 가리는 배너 광고나, 저절로 뜨는 전면 광고는 없어요.

### 5-8. 개인정보와 커뮤니티

- 이름, 전화번호 같은 개인정보를 받지 않아요. 토스가 발급하는 익명 식별키로 기록과 코인을 저장해요.
